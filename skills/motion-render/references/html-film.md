# html の映像の作り方

新しく作る動画の映像は、1 枚の HTML として書く（音ハメの一打ごとの反応を書けるのは html の映像だけ）。`motion-render kit <work>` が
`<work>/film/kit/` にプレーヤー・音ハメの部品・スタイル・部品・フォント（Noto Sans JP と、手描きの作風用の Klee One）・GSAP・場面の秒数・曲の一打の一覧を置くので、
Claude は `<work>/film/index.html` と、場面を書いた `<work>/film/scenes/*.html` だけを書く。描画中はネットワークが遮断されるので、CDN や Google Fonts は使えない。

## ページの骨組み

```html
<!doctype html>
<html lang="ja">
  <head>
    <meta charset="utf-8" />
    <link rel="stylesheet" href="kit/fonts.css" />
    <link rel="stylesheet" href="kit/base.css" />
    <link rel="stylesheet" href="kit/styles.css" />
    <link rel="stylesheet" href="kit/parts.css" />
    <script src="kit/gsap.min.js"></script>
    <script src="kit/timing.js"></script>
    <script src="kit/player.js"></script>
    <script src="kit/beat.js"></script>
    <style>
      /* 暗い平面の作風。ほかの作風では :root と body の色を書かず、<body data-style="paper"> のようにする */
      :root {
        --ground: #0b1622;
        --panel: #12233a;
        --line: #2a4466;
        --ink: #e9f0f7;
        --muted: #8aa0b8;
        --accent: #3ed6c4;
        --danger: #ff6b6b;
      }
      body {
        background: var(--ground);
        color: var(--ink);
      }
      /* …場面ごとのスタイル… */
    </style>
  </head>
  <body>
    <div id="root">
      <!-- 場面をまたいで残るもの（図の全体） -->
      <div id="stage">…</div>
      <!-- 場面ごとのもの（film/scenes/*.html）が、名前の順にここへ入る -->
      <!-- scenes -->
    </div>
    <script>
      // #stage の物の動き。場面のファイルの動きは、それぞれのファイルの film.build に書く
      film.build(function (tl) {
        tl.to("#token", { ...film.spot("#token", "#sts"), duration: 0.8, ease: "power2.inOut" }, film.at("sts", 0.6));
      });
    </script>
  </body>
</html>
```

プレーヤーが用意するもの:

| 名前                                 | 意味                                                                                           |
| ------------------------------------ | ---------------------------------------------------------------------------------------------- |
| `film.build(fn)`                     | フォントの読み込みが終わってから `fn(tl)` を呼ぶ。場面の図の出し入れはこの中に書く             |
| `film.draw(fn)`                      | コマごとに `fn(t)` を呼ぶ。音ハメの動きは全部この中に、時刻 `t` だけから書く（下の「音ハメ」） |
| `film.at(id, 秒)`                    | 場面 `id` の頭から何秒目か（動画の先頭からの秒に直す）                                         |
| `film.end(id, 秒)`                   | 場面 `id` の終わりの何秒前か                                                                   |
| `film.spot(要素, 相手, dx, dy)`      | `要素` の中心を `相手` の中心へ（`dx`・`dy` だけずらして）動かす GSAP の `x`・`y`              |
| `film.arc(tl, 要素, 相手, 秒, o)`    | `要素` を `相手` へ山なりに動かす。o: `dur`（既定 0.9）・`lift`（既定 120px）・`dx`・`dy`      |
| `film.breathe(tl, 要素, id, 秒, 量)` | `秒` から場面 `id` の終わりまで、`要素` を `量`（既定 0.01）だけゆっくり拡大縮小する           |
| `film.typeIn(tl, 要素, 秒, o)`       | `要素` の文字を 1 文字ずつ下から立ち上げる。o: `dur`（既定 0.5）・`stagger`（既定 0.04）       |
| `film.light(tl, 要素, 秒, o)`        | 部品の `step`・`card` を `秒` に光らせる。o: `off`（消す秒）・`dur`（既定 0.35）               |
| `film.ticks(要素, o)`                | 部品の `ruler` に目盛りを付ける。o: `step`（間隔）・`label`（既定 `"{v}"`、`""` で無し）       |
| `film.caption(tl, 要素, id, 秒)`     | 字幕を `秒` に出し、場面 `id` の終わりの 0.25 秒前までに消す                                   |
| `section.scene`                      | その場面の間だけ見える。`#stage` のように section の外に置いたものはずっと見える               |

## 音ハメ

曲（`motion-render score` が並べた曲）に映像を合わせる。新しく作る動画では必ず入れる。
基準は、ロケットの打ち上げを 172 BPM のドラムンベースで見せた 90 秒の動画: 全開ではエンジンの炎が全部のキックに乗り、
2 回の全開で画面全体が変わり、大きな文字は一打で着地して 2 小節残った。曲が止まったのは秒読みの 0 の 1 回だけだった。
これを下回らないように作る。

この動画が自然に見えたのは、一打で動く物すべてに、その一打で動く理由が話の中にあったからである。キックは推力なので
炎が伸び、止めは秒読みの 0 なので曲が止まった。理由の無い物（文字、背景、飾り、自分の拍を持つ心臓）を一打ごとに跳ねさせると、
合わせるために入れた動きに見える。映画音楽で、画面の動きを音が一つ残らずなぞる書き方を「ミッキーマウジング」と呼び、
多用すると安っぽく見えるとされるのと同じである。

### 時間を決める順番

語り → 映像 → 曲。語りが場面の秒を決め（`narrate`）、映像はその秒の中で山場を作り、曲は山場に合わせて並べる。
曲の都合で語りを止めない。区間の頭（`section`）はすでに小節の頭にあり、一打の一覧（`beat.hits`）は曲から測った実際の時刻。

### 必ず入れる演出

山場では、多少過剰に感じても次を全部入れる。下の「抑えるもの」より優先する（山場以外の場所では「抑えるもの」に従う）。

まず、全開でキックに応える物（以下「動力」）を 1 つ決める。一打で動く理由がその物にあること: エンジン（推力）、
ピストン・プレス・ハンマー（打つ）、送信機のランプ（送る）、印字機（打ち出す）、ポンプ（押し出す）。
テーマにそういう物が無ければ、話の中に作る（荷物を押し出す機械、データを打ち出す装置）。

| いつ                                     | 必ず入れるもの                                                                                                                                                         | 書き方の例                                         |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 全開の区間の毎キック                     | 動力がその物らしく応える（炎が伸びる、ピストンが突く、ランプが灯る）。大きさを 1 + 0.3〜0.45 × 強さにし、8 分音符の長さ以内に戻す                                      | `1 + 0.4 * beat.pulse(kicks, t, SNAP)`             |
| 全開の区間のスネア                       | 一打で動く理由のある物があれば 1 つだけ応えさせる（速さの話なら速度の線、打つ物なら火花、計器なら針）。無ければ入れない。8 分音符の長さ以内に消す                      | `1 - beat.since(snares, t) / SNAP`                 |
| 全開の外（`intro`・`groove`・`outro`）   | 一打ごとの反応は入れない。場面の動き（カードが出る、チップが着く、線が引かれる、数字が変わる）の始まりを、一番近い一打か拍の時刻に置く。動きそのものが拍に乗って見える | `tl.to(el, {…}, beat.snap(film.at("scene", 1.2)))` |
| 溜め（全開の前の区間）                   | 一打ごとに一段ずつ進める: カメラが 1 打ごとに寄る（合計 +12%）、メーターが 1 打ごとに埋まる、部品が 1 つずつ点く                                                       | `beat.steps(roll, t)`                              |
| 止め（1 本に 1 回、全開の直前の 1 小節） | 画面も止める: 背景を暗くする（明るさ 0.45）、動力が縮こまる（縦 0.96）、カメラはそのまま                                                                               | `t >= STOP - beat.E`                               |
| 全開の 1 拍目                            | 4 つを同時に: 閃光（0.85、0.18 秒）、画面全体の揺れ（18px から減衰、0.55 秒）、動力の切り替え（姿勢・大きさ・色）、大きな文字の着地                                    | `beat.flash`、`beat.shake`、`beat.words`           |
| 2 回目の全開                             | 1 回目と違う見た目にする: 配色を変える、動力を替える、反応をもう一段強くする                                                                                           |                                                    |
| 最後の一打                               | 決め: ほかを全部消し、題を 1 つだけ残す。閃光 0.7                                                                                                                      | `t >= beat.end - beat.E`                           |

- **一打で動かさない物を決める。** 文字、背景、飾りは一打で跳ねさせない。自分の拍を持つ物（心臓、時計、振り子、歩く足）は、
  キックの不規則な並びで動かさず、曲の拍（`beat.beat` ごと）で規則正しく動かす。キックに乗せると、心臓が乱れて打つように見える
- **楽器ごとに担当を 1 つ。** 1 つの一打を 2 つの物に当てない。ハイハットに担当は要らない
- **強さに階層をつける。** 拍に乗る場面の動き < 溜めの段 < 全開の動力 < 全開の 1 拍目。画面全体を使うのは全開の 1 拍目・止め・最後の一打だけ
- **話の出来事を一打に乗せる。** エンジンの点火、部品が外れる、数字が変わる瞬間は `beat.snap(その秒)` の時刻に置く

### 読みやすさの決まり

音ハメで画面を動かしても、読ませる物は読めるようにする。

- 読む物（章の見出し、数字、大きな文字）はカメラの外（`#cam` の外）に置き、揺らさず拡大しない。数字への一打の反応は色だけにする
- 大きな文字は `beat.words` で出す。一打で着地して 2 小節（2 秒以上、4 文字あたり 1 秒以上）残り、続けて来る語は前の語を
  小さくして上の段へ送る。文字の帯の上に 1 行分の空きを残す。幅は主役にかからないようにする
- 5px 未満の震えは使わない（位置がずれて見える）。閃光は 1 秒に 3 回まで
- 背景（空・地面）はカメラの外に画面いっぱいで置く。カメラが寄ったり揺れたりするときは、地面の線の高さだけをカメラに合わせて計算する
  （画面より大きな要素は `check` が「画面で切れている」と止める）

### 書き方: `film.draw` と `kit/beat.js`

音ハメの動きは、index.html の `film.draw(function (t) { … })` 1 つに書く。`t` だけから、その瞬間の値を全部計算して書く。

- GSAP のタイムラインに音ハメの動きを書かない。GSAP は動きの開始値を覚えて、巻き戻すとそこへ戻すので、
  同じ値を 2 つの動きが書くと、書き出しと静止画で絵が変わる（`check` が「changes after seeking back」で止める）
- 1 つの値を書くのは 1 か所だけ。値は「基準の値 + 一打ごとの上乗せ」で作る
- 場面の図の出し入れは今までどおり `film.build` でよい。ただし同じ要素の同じ値（`transform` など）を、`film.draw` と GSAP の両方で書かない

`kit/beat.js` が用意するもの（すべて時刻 `t` だけから値を返す）:

| 名前                                                            | 意味                                                                                                                      |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| `beat.pick({ k, from, to, min })`                               | 曲の一打の一覧。`k` は `"kick"`・`"snare"`・`"rim"`・`"ghost"`・`"hat"` かその配列、`from`〜`to` は秒、`min` は強さの下限 |
| `beat.pulse(list, t, dur)`                                      | `list` の一打のコマで 1、`dur` 秒かけて 0 に戻る値（一打の強さを掛けてある）。基準の値に足す                              |
| `beat.since(list, t)`                                           | 直前の一打から何秒たったか（まだ無ければ Infinity）。一打ごとに一度走る物に使う                                           |
| `beat.steps(list, t, dur)`                                      | 一打ごとに 1 段ずつ増える値（0 → `list.length`）。溜めの寄り、メーター                                                    |
| `beat.snap(秒)`                                                 | その秒に一番近いキックかスネア（半拍以内）、無ければ一番近い拍の時刻。場面の動きの開始を曲に乗せる                        |
| `beat.track([[t0, a, b, dur, ease], …])`                        | 動きの並び。`(t, 始めの値)` を渡すと、`t` までに始まった最後の動きの値を返す                                              |
| `beat.shake(t, t0, amp, dur)`                                   | `t0` の一打からの揺れ `{x, y}`（`amp` px から減衰、既定 0.55 秒）                                                         |
| `beat.flash(t, times, peak, dur)`                               | `times` の各時刻の閃光の不透明度（既定 0.85、0.18 秒）                                                                    |
| `beat.words([{ el, t, soft }])`                                 | 大きな文字の描き方を返す（`film.draw` の中で `words(t)`）。中の `<b>` は下線として左から引かれる                          |
| `beat.place(el, { x, y, s, sx, sy, r, o })`                     | 位置・大きさ・回転・不透明度をまとめて書く                                                                                |
| `beat.alpha(el, a)`                                             | 不透明度と表示をまとめて書く（0 で非表示）                                                                                |
| `beat.mix(色1, 色2, p)`                                         | 2 色の間の色                                                                                                              |
| `beat.ease`・`beat.prog(t, t0, d)`                              | 緩急（`out2` など GSAP と同じ形）と、`t0` から `d` 秒の進み具合（0〜1）                                                   |
| `beat.drops`・`beat.end`・`beat.sections`・`beat.bar`・`beat.E` | 全開の時刻、最後の一打の時刻、区間の一覧、1 小節の秒、一打を早めて見せる秒（0.008）                                       |

雛形（動力 `#flame`、背景 `#sky`、カメラ `#cam`、閃光 `#flash`、大きな文字 `#w-go` などは index.html に置く）。
1 回目の全開の前に 1 回だけ止め、2 回目の全開は落ち着いた区間 `cruise` から溜めて途切れずに入る:

```html
<script>
  var DROP1 = beat.drops[0],
    DROP2 = beat.drops[1],
    END = beat.end,
    E = beat.E;
  var STOP = DROP1 - beat.bar; // 1 本に 1 回の止め（秒読みの 0）
  var CALM = film.at("cruise"); // 1 回目の全開の後の落ち着いた区間
  var SNAP = Math.min(0.2, 30 / beat.bpm); // 一打の反応は 8 分音符の長さ以内に戻す
  var inDrop = function (h) {
    return (h.t >= DROP1 && h.t < CALM) || (h.t >= DROP2 && h.t < END);
  };
  var kicks = beat.pick({ k: "kick" }).filter(inDrop),
    roll = beat.pick({ k: "kick", from: STOP - beat.bar, to: STOP }), // 止めの前の小節
    rise = beat.pick({ k: ["kick", "snare"], from: DROP2 - 2 * beat.bar, to: DROP2 }); // 2 回目の溜め
  var words = beat.words([
    { el: "#w-go", t: DROP1 },
    { el: "#w-again", t: DROP2 },
  ]);
  film.draw(function (t) {
    var over = t >= END - E;
    // カメラ: 溜めで 1 打ごとに寄り、全開で戻して揺らす
    var push =
      t < DROP1 - E
        ? 1 + (0.12 * beat.steps(roll, t)) / Math.max(1, roll.length)
        : t >= CALM && t < DROP2 - E
          ? 1 + (0.08 * beat.steps(rise, t)) / Math.max(1, rise.length)
          : 1;
    var a = beat.shake(t, DROP1, 18),
      b = beat.shake(t, DROP2, 18);
    beat.place("#cam", { x: a.x + b.x, y: a.y + b.y, s: push, o: over ? 0 : 1 });
    // 止めの 1 小節は画面も止める
    var stop = t >= STOP - E && t < DROP1 - E;
    document.querySelector("#sky").style.filter = stop ? "brightness(0.45)" : "none";
    // 動力: 全開の区間だけ、キックごとに炎が伸びる。2 回目の全開から色を替える
    beat.place("#flame", { sy: (stop ? 0.9 : 1) + 0.4 * beat.pulse(kicks, t, SNAP) });
    document.querySelector("#flame").style.color = t >= DROP2 - E ? "var(--accent2)" : "var(--accent)";
    // 閃光と大きな文字、最後の一打の決め
    beat.alpha("#flash", Math.max(beat.flash(t, [DROP1, DROP2]), beat.flash(t, [END], 0.7)));
    words(t);
    beat.alpha("#title-end", over ? 1 : 0);
  });
</script>
```

場面の図の出し入れ（`film.build` の GSAP）は、開始の秒を `beat.snap` に通して曲に乗せる:
`tl.from("#card-a", { y: 40, autoAlpha: 0, duration: 0.3 }, beat.snap(film.at("route", 1.2)))`。
GSAP で出し入れする物は `opacity` でなく `autoAlpha` で隠す（隠れた物が配置の確認で見えている扱いにならない）。

### 一打を役に割り当てる

一打の一覧は `motion-render score` の後に `kit/timing.js` に入り、`build` が毎回書き直す。曲を並べ直しても映像は書き直さない。

- 役は時間で決める: `beat.pick({ k: "kick", from: film.at("ignite"), to: DROP1 }).slice(0, 9)` で「点火の場面の最初の 9 打」をエンジン 9 基に当てる
- 区間ごとに担当を変えてよい（溜めではメーター、全開では炎）。1 つの一打を 2 つの物に当てない
- 曲が鳴っていない区間（止め、無音の小節）では一打の反応を出さない。単発の一打だけを決めの動きに使う

## 作る前に決めること

`index.html` を書き始める前に、ページの先頭に HTML のコメントで次を 5〜8 行で書く。依頼文に書かれた指定
（雰囲気、対象の人、色）とテーマから決め、利用者には聞かない。場面を書くたびにこのコメントに照らして、
外れたものを直す。

- **作風**: 下の「作風」の表から 1 つ選ぶ。1 本の中で変えない
- **1 本を通す発想を 1 つ**: 「1 枚の図が書き足されていく」「1 つのトークンが旅をする」のように、
  全場面をつなぐ見せ方。場面ごとの見せ方も 1 つに絞る
- **配色**: 地・面・線・文字に加えて、強調 1 色と危険 1 色。強調色を増やさない。暗い平面以外は作風の色を使う
- **文字の役割**: 見出し・本文・字幕・数字（`num`）の大きさと太さ
- **動きの決まり**: 出る・移る・消えるの緩急と、止めて読ませる長さ。同じ役割の物には同じ動きを使う
- **この 1 本で使わないもの**: 下の「抑えるもの」から、テーマに合わせて足す

## 絵コンテと秒の計画

場面を書き始める前に `<work>/plan.md` を書く。場面を手分けして書くときの共通の指示書であり、効果音を先に作る元でもある。
秒は `timing.json` の場面の長さに収める。場面ごとに次の 5 つを書く。

```markdown
## flow（12.4 秒）
- 見せるもの: 6 つの工程カードが左から並び、今の工程が光る
- 部品: steps（6 枚）、caption
- 動き: 0.3 カードが順に出る（0.08 ずつ）／ 1.6 「原稿」が光る ／ 4.2 「ナレーション」が光る ／ 8.0 字幕
- 効果音: 0.3 soft UI pop 0.6 ／ 1.6 gentle glassy chime 1.0 ／ 4.2 gentle glassy chime 1.0
- 残る物: #steps は入るとき無い → 出るとき上端に縮んで残る（次の場面 lanes が使う）
```

- 動きの秒は、その動きに渡す `film.at(場面, 秒)` の秒にする。書き手はこの秒を変えない
- 場所は id で指す（「`#st-mix` の真下」）。座標を書くのは、画面の割り当て（どの帯に置くか）だけにする。
  中身の大きさで位置が変わる物（並んだカードの 2 枚目以降）を座標で書くと、書き手の計算とずれる
- 残る物（`#stage` の物）は、場面の頭と終わりの状態（位置・大きさ・見えるか）を書く。
  まとまりの境目の場面ほど詳しく書く。境目で物が飛ばないようにするため
- 効果音は `prompt` と `duration` まで書く。そのまま `script.json` の `sfx` に写す

## 作風

依頼文に見た目の指定（「手描きで」「ホワイトボードで」「設計図っぽく」）があればそれに合う作風にする。
指定がなければ、テーマの中身で選ぶ。利用者には聞かない。迷ったら暗い平面にする。

| 作風           | `data-style` | 合うテーマ                                                 | 見え方                                                                   |
| -------------- | ------------ | ---------------------------------------------------------- | ------------------------------------------------------------------------ |
| 暗い平面       | （付けない） | ソフトウェアの仕組み、セキュリティ、インフラ、データの流れ | 暗い地に、色を絞った平らな図                                             |
| 紙と鉛筆       | `paper`      | 考え方、アイデア、設計の発想、研究の要点、働き方の変化     | 白い紙に、揺れる鉛筆の線と斜線の陰、黄土色の強調と蛍光ペン、手書きの文字 |
| 色鉛筆         | `crayon`     | 初めての人や子ども向け、暮らし、健康、物語                 | 暖かい紙に、太くやわらかい線と、紙の目が透ける塗り                       |
| 設計図         | `blueprint`  | 機械、建物、部品の構造、システムの構成                     | 青い地に白い方眼と、揺れないきれいな白い線                               |
| 紙コラージュ   | `collage`    | 会社やチームや人の紹介、歴史、事例                         | クラフト紙の上に、破った色紙をテープで貼る                               |
| ホワイトボード | `whiteboard` | 授業、数式、理論、アルゴリズム                             | 白い板に、マーカーの線と手書きの文字                                     |

`data-style` を付けると、地・面・線・文字の色（`--ground` `--panel` `--line` `--ink` `--muted`
`--accent` `--danger`、蛍光ペンの `--mark`、塗りの `--tint-1`〜`--tint-4`）、紙の目や方眼、文字の書体が決まる。ページでは色をこの変数で書き、別の色を足さない。
紙の目と方眼は `#root` の後ろに描かれ、`check` は文字の色の差を `--ground` や面の色に対して測る。

作風の部品（どの作風でも同じ名前で使え、作風ごとに見え方が変わる）:

| クラス・変数                   | 使うもの                                                                                                                                                          |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `drawn`                        | カード・枠。手で引いた枠線を描く。`style="--fill: var(--tint-2)"` で中を塗る。中の文字は揺らさない                                                                |
| `sketch`                       | 線の図（矢印・アイコン・グラフの線の `<svg>`）。線が手描きのように揺れる。文字を持つ要素には付けない                                                              |
| `hatch`                        | 棒グラフの棒や図形の陰。`color` の色の斜線で塗る。上に文字を置かない                                                                                              |
| `url(#mr-hatch)`               | `<svg>` の図形（人の胴、箱）の `fill`。`--line` の斜線で塗る。`url(#mr-hatch-accent)` は `--accent` の交差した斜線。図形には `sketch` も付ける                    |
| `marker`                       | 見出しや大事な語の後ろに蛍光ペンを引く。GSAP で `{ "--mark-x": 0 }` から `{ "--mark-x": 1 }` へ動かすと左から引かれる。上の文字は `--ink` のままにする            |
| `tooth`（`crayon`）            | 文字のない図形を色鉛筆で塗ったように、紙の目を透かす                                                                                                              |
| `cutout`・`taped`（`collage`） | 紙片。破れた縁と影を付ける。`--fill` で紙の色（`--tint-1`〜`--tint-4`）を選び、`taped` で上にテープを貼る。縁が 20px ほど外へ出るので、紙片の間を 40px 以上あける |

- 手描きの線は、プレーヤーが 1 秒に 8 回描き直して小さく揺らす（同じ時刻はいつも同じ絵になる）。
  線を描き足すときは今までどおり `stroke-dashoffset` で引く
- 紙コラージュの紙片は GSAP の `rotation` で -2〜2 度傾け、場面に入るときは上から置くように落とす
- ホワイトボードと紙と鉛筆では、説明の順に線と文字を書き足していく（1 枚の板・1 枚の紙を最後まで使う）
- 作風が紙の目や揺れを足すので、ページでは模様や影を足さない
- `Klee One` の太字は 600 まで。`font-weight: 700` は 600 で描かれる

## 部品

`kit/parts.css` に、解説の映像で毎回描く形がある。場面では中身と秒だけを書き、形を一から書かない。
色はページの変数（`--panel` `--line` `--ink` `--muted` `--accent`）から取るので、どの作風でも使える。
手描きの作風では `step`・`card` に `drawn` も付ける（線は作風が描き、部品は光らせるだけにする）。

| 部品         | 書き方                                                                                                                                                                                                                                                                                                   | 動かし方                                                                 |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 工程の列     | `<div class="steps layer-card" style="left:…; top:…">` の中に `<div class="step"><svg>…</svg><span>原稿</span></div>` を並べる                                                                                                                                                                           | `film.light(tl, "#s-script", 秒, { off: 秒 })`                           |
| カード       | `<div class="card layer-card" style="position:absolute; left:…; top:…">` に `<span class="card-title">` と `<span class="card-body">`                                                                                                                                                                    | `film.light` で光らせる。出し方は自分で書く                              |
| 時間のレーン | `<div class="lanes layer-card" style="--from: 0; --to: 20; left:…; top:…; width:…">` に `<span class="lane-name">語り</span><div class="track">…</div>` を組で並べる。`track` の中に `<div class="seg" style="--at: 2; --len: 5.8"><span>場面 1</span></div>` と `<i class="pin" style="--at: 7.5"></i>` | `seg`・`pin` を GSAP で出す（`scaleX` で伸ばす、`scale` で跳ねる）       |
| 目盛り       | `<div class="ruler layer-line" style="--from: 14; --to: 26; left:…; top:…; width:…">`                                                                                                                                                                                                                    | `film.build` の中で `film.ticks("#ruler", { step: 2, label: "{v} 秒" })` |
| 字幕         | `<p class="caption layer-caption">…</p>`                                                                                                                                                                                                                                                                 | `film.caption(tl, "#cap-flow", "flow", 秒)`                              |

- `seg` と `pin` の位置は、`lanes` の `--from`〜`--to` を `track` の幅に当てて決まる。秒でも、ほかの単位でもよい
- 1 本の `track` の中で `seg` と `pin` を重ねない（`check` が重なりとして出す）。印は別の `track` に置く
- 大きさは変数で変えられる: `--step-w`（工程の幅）、`--steps-gap`、`--lane-h`（レーンの高さ）、`--ruler-pad`、`--tick-w`（目盛りの文字の幅）

## 配置の決まり

`motion-render check` はこれを破った所を見つけて止める。最初から守って書く。

1. **関係のあるものは、親子にしてレイアウトで並べる。** カードの中身（見出し、説明、チェック項目、
   中に入るチップ）はカードの子要素にし、`display: flex` / `grid` と `gap` で並べる。
   画面全体の座標（`position: absolute; left: …px`）で 1 つずつ置くのは、図の大きな部品（カード、
   字幕、流れ図）だけにする。子の箱（アイコン、下線）を持つ要素の文字は `<span>` で包む。
   文字を直に持つ要素は `check` が文字の範囲で測るので、文字の外にある子がはみ出しと出る
2. **印は、判定する相手の中に置く。** ✕・✓・バッジ・番号は、それが付く要素の子にする
   （`<div class="chip">OIDC トークン<span class="mark">✕</span></div>`）。2 つの要素の間の
   空いた所に浮かせない。拒否を見せるときは、チップを相手にぶつけて跳ね返し、チップに ✕ を出し、
   相手の枠を一瞬赤くする
3. **重なり順は役割で決める。** 位置を持つ要素には `kit/base.css` の層のクラスを 1 つ付ける。
   HTML に書いた順番に頼らない

   | クラス          | 使うもの                       |
   | --------------- | ------------------------------ |
   | `layer-bg`      | 背景、グラデーション           |
   | `layer-card`    | カード、パネル、枠             |
   | `layer-line`    | 矢印、つなぐ線、グラフの補助線 |
   | `layer-chip`    | 動くチップ、トークン           |
   | `layer-mark`    | ✕・✓・強調の輪                 |
   | `layer-caption` | 字幕                           |

4. **チップの行き先は `film.spot` で決める。** 止まる位置は、カードの中に収まるか、どのカードとも
   重ならない所にする。カードの枠線をまたいで止めない。SVG の要素（アイコンの `<svg>`、図の中の図形）も
   `film.spot`・`film.arc` で動かせる
5. **箱は親の中に収める。** 親より大きくなりそうな中身は、文字を短くするか親を広げる。
   はみ出しを `overflow: hidden` で隠さない
6. **前の場面の残りを片付ける。** 次の場面で使わない部品は、場面の頭で消すか薄くし、新しい部品と
   同じ場所に重ならないようにする

意図した重なり（グラフの基準線が棒を横切る、軸のラベルが目盛りの外に出る、わざと斜めに押す判子）は、
その要素に `data-layout-ok` を付けると `check` が数えない。間違いを黙らせるためには使わない。

## 場面を分けて書く

場面は `film/scenes/<番号>-<名前>.html` に、続いた場面のまとまりごとに書く。プレーヤーが開くとき、
`index.html` の `<!-- scenes -->` の行に、ファイル名の順で差し込まれる。1 つのファイルには、
その場面の `<style>`、`<section class="scene">`、`<script>film.build(…)</script>` を書く。

```html
<style>
  #flow .steps { left: 260px; top: 180px; }
</style>
<section class="scene" id="flow">…</section>
<script>
  film.build(function (tl) {
    film.light(tl, "#flow-s1", film.at("flow", 1.6));
  });
</script>
```

- 音ハメの層（index.html の `film.draw`、カメラ、閃光、大きな文字、計器）は分けない。Claude が index.html に 1 つで書く。
  場面のファイルは、その場面の図の出し入れだけを書き、音ハメの層が動かす要素の値を書かない
- id はページ全体で 1 度だけ。場面の id を頭に付ける（`#flow-s1`）
- スタイルは `#場面id` で始める。ほかの場面に効かせない
- `index.html` は書き換えない。`#stage` の物は自分の場面の秒の間だけ動かし、場面の終わりに plan.md の状態にする
- 自分のファイルだけを `motion-render check <work>/film <ファイル名>` で調べる。ほかのファイルを入れずに、
  自分の場面の秒だけを調べる。`layout ok` になり、`runner` の行が出なくなるまで直す
- 静止画は 1 回だけ、自分の場面の中ほどの秒で見る。全体の見た目は、全員が返ったあとに Claude がまとめて見る

まとまりは続いた 2 場面ずつにする（最大 7）。書き手の時間は、手引きを読む決まった時間と、場面の数に比例する時間の和なので、
1 人あたりの場面を減らすほど全員がそろって早く返る。ベンチマーク（14 場面）では、3〜4 場面ずつの 4 人だと最も遅い 1 人が
8 分 40 秒かかり、2 場面ずつの 7 人だと 5 分 15 秒だった（ほかの 6 人は 2 分 24 秒〜3 分 45 秒）。
書き手 1 人あたり 12〜15 万トークンを使うので、7 人で 1 本あたり約 90 万トークンになる。

サブエージェントに頼むときは、1 つのまとまりに 1 つ、次を渡す。

```
<work>/film/scenes/<番号>-<名前>.html に、場面 <id>, <id>, … を書いてください。
- 先に読むもの: <skill>/references/html-film.md、<work>/plan.md、<work>/film/index.html、<work>/timing.json
- plan.md の各場面の「動き」の秒と「残る物」の状態を守る。index.html は変えない
- 書いたら `motion-render check <work>/film <番号>-<名前>.html` を `layout ok` になるまで直す（単体で実行する）
- 静止画は 1 回だけ見る。plan.md に無い細部は自分で決め、問い返さない
- 返すもの: ファイル名、plan.md から変えた秒（無ければ「なし」）、直しきれなかった問題
```

## 確認

```bash
motion-render check <work>/film
```

0.1 秒ごとに全体を調べ、止まっている部品について次を出す。動いている途中の重なりは数えない。
0.2 秒以上同じ状態で止まっていれば出る。

| 出力                                   | 意味と直し方                                                                                                                                                |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `A and B partly overlap`               | 2 つが中途半端に重なっている。片方をもう片方の中に入れるか、離す                                                                                            |
| `A sticks out of B`                    | 子の A が親の B からはみ出している。中身を減らすか B を広げる                                                                                               |
| `A is cut off by the frame`            | 画面の端で切れている。安全域（左右 144px、上下 81px）の中へ入れる                                                                                           |
| `A is hidden under B`                  | A の大部分が B の下に隠れている。層のクラスを見直すか、位置をずらす                                                                                         |
| `A is 20px, smaller than 24px`         | 文字が小さすぎる。24px 以上にする                                                                                                                           |
| `A has contrast 2.1:1, needs 4.5:1`    | 文字が背景に対して薄い。40px 未満は 4.5:1、40px 以上は 3:1 を超えるよう、文字か背景の色を変える。明るい色の丸やチップに乗せる数字は、地の色（暗い色）で書く |
| `A is on screen for 0.5s, needs 2.0s`  | 40px 以上の文字が、場面の途中で読む前に消える。2 秒以上かつ 4 文字あたり 1 秒以上残す（大きな文字は `beat.words`）。場面の終わりまで残る文字は数えない      |
| `the frame changes after seeking back` | 同じ時刻でも、前にどこまで再生したかで絵が変わる。その時刻の動きを `film.draw` に移すか、同じ値を書く GSAP の動きを 1 つにする                              |

`layout: ok` になるまで直してから `stills` で見る。`build` は問題が残っていると止まる。

`build` の後の `sync problem:` の直し方:

| 出力                                                                                                                  | 直し方                                                                                            |
| --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `drop "…": the picture changes only 1.2x`                                                                             | 全開の 1 拍目に、閃光・画面全体の揺れ・主役の切り替えを同時に入れる（`beat.flash`・`beat.shake`） |
| `final hit …: the picture changes only`                                                                               | 最後の一打で、ほかを全部消して題だけを残し、閃光を入れる                                          |
| `… the change is 40 ms off the hit`                                                                                   | 山場の動きの秒を `beat.drops`・`beat.end` から取る（場面の秒や手で書いた秒を使わない）            |
| `kicks in the drops: the picture moves on 60% of them`                                                                | 全開の区間のすべてのキックで、動力を `beat.pulse` で動かす。8 分音符の長さ以内に戻す              |
| `kicks in the drops: … 70% with no hit`                                                                               | 動力の反応が次の 8 分音符まで残っている。`dur` を `30 / beat.bpm` 以下にする                      |

## 動き

- 役割で緩急を決める: 出るとき `expo.out`（0.4〜0.7 秒）、移動 `power2.inOut`（0.6〜0.9 秒）、
  消えるとき `power3.in`（0.2〜0.3 秒）。並んだものは 0.05〜0.1 秒ずらして出す
- 1 場面 1 つの出来事。図が動き終わってから字幕を出す。字幕は場面の終わりの 0.25 秒前に消す
- 場面の最後の動きのあと、1.5 秒以上止めて読ませる
- 秒数は `film.at` / `film.end` だけで書く。ナレーションを作り直しても `build` が秒数を読み直す

### 動きを豊かにする

文字のチップが出て止まるだけの映像は、内容が正しくても単調に見える。仕組みを説明する映像では、
画面のどこかが動いている時間を全体の 3 割以上にする。次をどの場面でも使う。

1. **名詞は絵にする。** 鍵・人・サーバー・書類のように説明の主役になるものは、インラインの SVG で
   描く（線の太さをそろえた単純な形、色は `currentColor`）。文字だけのチップは補助に回す
2. **移動は弧を描かせ、1 対多はずらして動かす。** `film.arc(tl, 要素, 相手, 秒, { lift })` で山なりに
   飛ばす。1 つのものが複数へ配られる・漏れる場面は、コピーを 0.2〜0.3 秒ずつずらして飛ばす
3. **出るときは少し跳ねる。** アイコン・数字・印は `scale` 0.6→1 を `back.out(1.7)` で出す。
   文字の行や大きなカードは跳ねさせず、`expo.out` で下から出す
4. **止まっている間も完全には止めない。** 場面の部品をまとめた要素を、場面の頭から終わりまで
   `scale` 1→1.02〜1.03 にゆっくり寄せる（`ease: "none"`）。いま注目させる要素には
   `film.breathe(tl, 要素, 場面, 秒, 0.01)` で微かな呼吸を付ける。決定的な瞬間（漏れる・拒否される）は、
   0.3 秒ほど小刻みに揺らすか、枠を一度光らせる
5. **届いたら相手が変わる。** チップが着いた瞬間に、相手の枠の色・アイコンの明るさを変える。
   受け取ったことが色で分かるようにする
6. **線は引く。** 矢印・下線・取り消し線は、`scaleX` 0→1（`transform-origin` を始点に置く）で描く。
   ふわっと出さない
7. **行って帰るまで見せ、結果は両方見せる。** 何かを受け取る流れは、受け取ったものを頼んだ側へ
   届けるところまで動かす（その場に出して終わりにしない）。条件で通す・止める場面は、通るものを
   先に通してから、止まるものを止める。移動は画面の端から端まで使ってよい

`film.breathe` で揺らす要素の `scale` は、同じ時間帯に別の動きで変えない。寄せる動きは、
`film.breathe` を付けた要素の親に付ける。

### 抑えるもの

映像の格は、足す物より削る物で決まる。テーマがはっきり求めるとき以外は使わない。
ただし音ハメの山場（全開・止め・最後の一打）では、上の「音ハメ」の「必ず入れる演出」を優先する。
画面全体の揺れ・閃光・寄り・色抜きは、そこで必ず使う。ここで抑えるのは、山場以外の場所での使い方。

- 粒子の飛び散り、光のにじみ、レンズの光、画面全体の揺れ、色ずれ
- 意味のない回転や立体の回転、理由のないズーム。寄せは場面ごとの 2〜3% だけにする
- 動き方の種類を増やすこと。出方は 2〜3 種類に絞る
- 印と数字以外の跳ねる動き。全部の物が同じ瞬間に動き出して同じ瞬間に止まること
- 説明の長い文を画面に置くこと。画面の文字は字幕と短いラベルにする
- 内容と関係のない飾り（漂う図形、意味のない背景の模様）

### 場面を物でつなぐ

境目で全部を消して新しく出し直すと、スライドをめくっているように見える。前の場面に残っている物を、
次の場面の部品に変えてつなぐ。

- 次の場面でも使う物は section の外（`#stage`）に置き、場面の頭で `film.spot` で新しい位置へ動かし、
  大きさ・色・角の丸みを変える。例: カードが縮んで次の場面の流れ図の 1 段になる、グラフの線が伸びて
  次の場面のつなぐ線になる、数字が次の場面の見出しの数字になる
- 最初から最後まで画面に残る主役の物（トークン、鍵、1 本の線）を 1 つ決めると、場面が 1 本につながる
- 全部を消して出し直すのは、話の章が変わる所だけにする
- `#stage` の物は場面が変わっても消えないので、使い終わったら自分で消す

### 文字を動かす

見出しと決めの言葉は、ふわっと出さずに 1 文字ずつ下から立ち上げる:
`film.typeIn(tl, "#t-title", film.at("title", 0.4))`。

- 文字だけを持つ要素に使う（中の子要素は文字に置き換わる）。1 行の見出し向けで、2 行なら行ごとに要素を分ける
- 言葉の意味と同じ向きに動かす: 「重い」は沈む、「支える」は下から持ち上げる、「詰まる」は字間を詰める
- 字幕と本文には使わない（読む速さが落ちる）。1 場面に 1 か所まで

### 仕組みを本物で見せる

説明の対象が過程（拡散、待ち行列、ランダムな歩み、増え方、ぶつかり合い）なら、それらしい絵を描く
代わりに、小さなシミュレーションを動かして見せる。

- 乱数はシード付きの関数（例: mulberry32）で作り、時刻 t だけで状態が決まるように書く。
  毎回 0 から t まで計算し直してよい（下の「決まった絵になるように」と同じ理由）
- 数字は実際の値を使い、原稿の数字と合わせる。推定の値には「約」を付ける
- 機械や構造は分解図で見せる: 部品が名前のラベルを付けて離れ、また組み上がる
- 大きさが桁で違うもの（地球から原子まで）は、目盛りを付けた連続のズームで見せる

## 文字

- `<html lang="ja">` と `kit/base.css` で、見出しは文節の切れ目で改行される。長いカタカナ語
  （セキュリティトークンサービス）は途中で割れるので、短い言葉か英語の表記にする
- 本文 28px 以上、字幕 52〜60px、見出し 40px 以上。出典や小さなラベルも 24px 以上。数字には `class="num"`（等幅の数字）
- 不透明度を 0.9 未満にした文字（わざと暗くした部品）はコントラストを測らない。読ませたい文字は薄くしない
- 色は `:root` の変数で決め、意味で使い分ける（正常・強調・危険）

## 決まった絵になるように

- 動きは `film.build` の中の GSAP のタイムラインか、`film.draw` で書く。CSS の `animation`・`transition`、
  `Date`・`Math.random`・`setTimeout`・`requestAnimationFrame` は使わない
- 同じ時刻はいつも同じ絵にする。`film.draw` の中で前のコマの値を覚えておかない。GSAP で同じ要素の同じ値を
  2 つの動きで書かない（巻き戻すと絵が変わる。`check` が止める）
- 数え上げは `onUpdate` で文字を書き換える（プレーヤーがコマごとに呼ぶ）
- 画像を使うときは `<work>/film/` の中に置き、相対パスで読む

## 効果音

`script.json` の `sfx` の `at` には、その音を鳴らす動きに渡した `film.at(場面, 秒)` の秒をそのまま書く。
例えば `tl.fromTo("#key", …, film.at("problem", 1.6))` に合わせる音は、場面 `problem` の `"at": 1.6`。
効果音を付けた動画は、タイトルの場面に `🎧:11.ai` を小さく入れる。
