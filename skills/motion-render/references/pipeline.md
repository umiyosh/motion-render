# 工程のつながり

1 本の動画は、Claude が書く工程と、API や描画を待つ工程でできている。待つ工程は、後の工程がその結果を
使うまで裏で動かし、Claude はその間も書き続ける。かかった時間は `motion-render times <work>` で見る。

## html の映像の工程

| 工程                      | する人                                 | 読むもの                                       | 書くもの                          | 待つ人                   |
| ------------------------- | -------------------------------------- | ---------------------------------------------- | --------------------------------- | ------------------------ |
| 原稿                      | Claude                                 | 依頼                                           | `script.json`（場面と語り）       | ナレーション             |
| ナレーション（`narrate`） | API（4 本ずつ）                        | `script.json`                                  | `audio/<場面>.wav`、`timing.json` | 計画（場面の秒数が要る） |
| BGM（`bgm`）              | API・裏                                | `script.json` の `bgm`、全体の秒               | `audio/bgm.*`                     | 書き出し                 |
| 絵コンテと秒の計画        | Claude                                 | `timing.json`                                  | `plan.md`                         | 効果音、場面             |
| 効果音（`sfx`）           | API（3 本ずつ）・裏                    | `script.json` の `sfx` の `prompt`・`duration` | `audio/sfx/`                      | 書き出し                 |
| 共通部分                  | Claude                                 | `plan.md`                                      | `film/index.html`                 | 場面                     |
| 場面                      | サブエージェント（まとまりごとに同時） | `plan.md`、`index.html`                        | `film/scenes/*.html`              | 確認                     |
| 確認（`check`・`stills`） | Claude                                 | 映像                                           | 直し、`sfx` の `at`               | 書き出し                 |
| 書き出し（`build`）       | 描画                                   | すべて                                         | MP4                               | —                        |

裏で動かすのは、結果を使う工程が先にあるものだけ。BGM は書き出しまで、効果音は書き出しまで誰も待たない。
ナレーションは場面の秒数を決めるので、終わるまで計画を書かない。

## 工程を足すとき

キューシートと BGM の合わせ込み（#42）のように工程を足すときは、次を決めてから入れる。

1. **読むものと書くもの**: 上の表に行を足す。読むものが揃う一番早い所に置く。秒は `plan.md` か、
   書いた映像の `film.at` の秒から取る（計画の秒ではなく、実際に書いた秒を正とする）
2. **誰が待つか**: 結果を使う工程が後ろにしかなければ、Bash の `run_in_background` で裏に回す。
   コマンドにするなら `scripts/steps.ts` の `BACKGROUND` に入れ、`times` が Claude の時間として数えるようにする
3. **Claude が書く量**: 場面ごとに分けられるもの（場面ごとの指示、場面ごとのキュー）は、場面のファイルと
   同じまとまりで分け、サブエージェントに同時に書かせられる形にする。全体を 1 人で通して書く工程を増やさない
4. **測る**: 足す前と後で同じ動画を作り、`motion-render times <work>` の表を PR に載せる。
   API を何度もやり直す工程（BGM を作り直すなど）は、回数も書く
